# Ishaan Bajpai — Portfolio

A visual-first portfolio built with Next.js, TypeScript and Framer Motion.

## Direction

The site is intentionally experience-first rather than résumé-heavy:

- Editorial typography and large negative space
- Visual project showcases instead of dense project cards
- Subtle motion and hover interactions
- Responsive layouts for desktop and mobile
- Minimal palette: warm paper, near-black and electric blue
- Technical details are present, but secondary to the experience

## Stack

- Next.js
- React
- TypeScript
- Framer Motion
- CSS

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Build

```bash
npm run build
npm start
```
